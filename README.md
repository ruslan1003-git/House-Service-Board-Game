# Домоуправ — базовый прототип

Небольшая браузерная игра про управление домом и деньгами управляющей организации.

## Запуск

Откройте `index.html` в современном браузере. Сборка и установка зависимостей не требуются. Игровой прогресс хранится в `localStorage` браузера.

Для разработки используйте отдельную платформу `dev.html`. Она повторяет текущую игру и добавляет боковую панель для создания тестовых заявок всех типов, изменения репутации и бюджета, переброса рынка труда, очистки штрафов и удаления действующих заявок. Тестовый прогресс хранится отдельно от обычной версии.

## Публикация для телефона

Игра работает как статический сайт. В репозитории уже подготовлен workflow GitHub Pages: после загрузки проекта в GitHub и включения Pages сайт будет публиковаться автоматически при каждом push. В опубликованную версию входят только `index.html`, `game.js` и `style.css`; dev-панель в сеть не выкладывается.

1. Создайте на GitHub пустой репозиторий, например `domouprav-game` (не добавляйте README или лицензию при создании).
2. В терминале из папки проекта выполните, подставив адрес своего репозитория вместо `ВАШ_АККАУНТ`:

   ```sh
   git add README.md index.html game.js style.css dev.html .github/workflows/deploy.yml
   git commit -m "Prepare game for GitHub Pages"
   git branch -M main
   git remote add origin https://github.com/ВАШ_АККАУНТ/domouprav-game.git
   git push -u origin main
   ```

3. В репозитории откройте **Settings → Pages** и выберите источник публикации **GitHub Actions**.
4. Дождитесь успешного запуска workflow **Deploy game to GitHub Pages**. Ссылка появится в **Settings → Pages** и в окружении `github-pages`.
5. Откройте ссылку в браузере телефона. В меню браузера выберите **Добавить на главный экран**.

Страница GitHub Pages доступна через интернет; не размещайте в проекте секреты и личные данные. Игровое сохранение остаётся в локальном хранилище браузера и отдельно на каждом устройстве. Подробнее: [официальная инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Правила первой версии

- Начало игры: 1 дом, площадь 10 м², капитал 100 ₽.
- Репутация директора начинается с +1 и относится к игроку, а не к дому.
- Один ход — один сезон. Порядок сезонов: лето, осень, зима, весна. После четырёх сезонов открывается годовой отчёт.
- Тариф: 10 ₽ за м². В конце хода случайно определяется собираемость от 20% до 100%, затем поступает соответствующая доля платежей с дома. Неполученная часть накапливается как долг дома.
- Базовое обслуживание дома стоит 30 ₽ за сезон независимо от заявок. Оно покрывает постоянные услуги дома.
- Порядок хода: найм и увольнение → приём заявок → выполнение заявок → выплата зарплат и сбор платежей.
- В начале хода рынок труда предлагает 5 случайных соискателей разных должностей из исполнителей и специалистов. На фазе менеджмента можно отметить несколько наймов и увольнений в кадровом пуле, вернуть любое решение без последствий и применить все изменения при переходе к заявкам. Без HR за ход можно выбрать до двух наймов; HR снимает лимит.
- Зарплата исполнителей за ход: сантехник — 20 ₽, электрик — 15 ₽, дворник — 15 ₽, разнорабочий — 20 ₽. Зарплата Юриста, HR-менеджера и Бухгалтера для прототипа установлена в 20 ₽ за ход.
- При наличии HR новые сотрудники проходят испытательный срок в два хода и получают половину обычной зарплаты. Их можно уволить без выплаты последней зарплаты; сохраняются общие правила репутации и риска жалобы в инспекцию. С HR премия за переработку уменьшается вдвое.
- Исполнители выполняют заявки своей категории. Специалисты не выполняют заявки: каждый Юрист получает отдельное поручение после распределения, может взыскать до 30 ₽ долга за ход либо с вероятностью 50% снизить выбранный штраф или компенсацию на 10–50%. Конкретный юрист может оспорить каждое обязательство только один раз. Бухгалтер суммирует взыскиваемые долги дома за периоды; без него долг прошлого периода становится безнадёжным при следующем начислении.
- Увольнение доступно в начале хода. Можно выплатить последнюю зарплату сотрудника или удержать её; увольнение без выплаты снижает репутацию на 1. Нанятые сотрудники получают зарплату в конце текущего хода.
- При увольнении без последней зарплаты сотрудник может пожаловаться в трудовую инспекцию. Для каждого такого случая шанс отдельно разыгрывается в диапазоне 0–50%; при жалобе появляется штраф в размере трёх зарплат.
- Штрафы и компенсации ведутся отдельно от заявок в панели игрока. Компенсация ущерба появляется там сразу при получении аварийной заявки и выплачивается только кнопкой в этом блоке. Выполнение заявки не оплачивает компенсацию. Неоплаченные обязательства лишают годового бонуса за отсутствие долгов. Юрист может попытаться уменьшить штраф или компенсацию. При банкротстве долги дома, штрафы и компенсации списываются.
- На каждый дом игрок получает 2 новые случайные заявки за ход. Категории: электрика, сантехника, уборка и общестрой.
- Каждая заявка имеет тип: обычная, аварийная, аварийная с ущербом или платная. Аварийные нельзя отменить вручную; они всё ещё могут получить статус «Отменена» при истечении срока в годовом отчёте.
- У заявки есть трудозатраты от 1 до 3; сложная работа занимает больше продуктивности исполнителя.
- Любую заявку можно поручить одному сотруднику подходящей категории или передать подрядчику за стоимость: зарплата требуемого специалиста + материалы + 10 ₽. Компенсация ущерба оплачивается дополнительно. Заявку нельзя разделить между сотрудниками.
- У части заявок есть отдельные расходы на материалы. При оплате заявки они включены в полную цену; при работе сотрудника стоимость материалов списывается отдельно.
- Аварийная заявка с ущербом создаёт отдельное обязательство на сумму с карточки; оно выплачивается через блок штрафов и компенсаций независимо от оплаты работ и материалов.
- Платная заявка приносит указанный доход при выполнении и не требует затрат на материалы. При работе сотрудником она занимает его продуктивность; при передаче подрядчику доход поступает вместе с выполнением и покрывает оплату подрядчика.
- Базовая продуктивность за ход: сантехник — 3, электрик — 3, дворник — 4, разнорабочий — 5 трудозатрат. Сотрудник может выполнить несколько заявок, если их суммарные трудозатраты помещаются в доступную продуктивность.
- Переработка оплачивается по формуле: зарплата сотрудника ÷ продуктивность × число трудозатрат сверх оставшейся продуктивности. Заявка сначала использует свободную продуктивность сотрудника и начисляет премию только за превышение. Премия списывается при назначении переработки.
- При отказе от премии сотрудник завершит работу, но будет недоволен весь следующий ход, а его продуктивность снизится на 1. После выплаты зарплаты в конце этого следующего хода он вернётся к базовой продуктивности и сможет снова перерабатывать за премию.
- Нерешённые заявки остаются на доме и переносятся в следующие сезоны, где к ним добавляются новые заявки. В годовом отчёте все оставшиеся заявки получают статус «Отменена» и больше не переносятся.
- Годовой отчёт показывает капитал на начало и конец года, принятые, выполненные и отменённые заявки, а также наймы и увольнения — отдельно за год и за всю игру. Счётчик отменённых заявок на доме сохраняется между годами.
- В годовом отчёте каждые 3 отменённые за этот год заявки снижают репутацию на 1. Если у игрока нет долгов, репутация повышается на 1; если отменённых заявок нет — ещё на 1.
- Заявку можно отменить вручную; она сразу учитывается как отменённая и больше не переносится.
- При балансе −500 ₽ или ниже необходимо объявить банкротство. Сотрудники распускаются, заявки закрываются, дом снимается с управления, долги списываются. Новая УК начинает с 100 ₽, репутацией −1 и случайным домом из колоды; базовое обслуживание нового дома — 30 ₽ за сезон.
- Карточка дома показывает адрес, площадь, тариф, текущую и общую собираемость, долг, базовое обслуживание, а также действующие и отменённые заявки. Сводка компании показывает портфель, сборы, отмены за текущий год, расходы на зарплаты и обслуживание, а долг делится на взыскиваемый, доступный юристам сейчас и безнадёжный.
- Неистраченный капитал переносится между ходами; оплату ремонта можно отложить.
- Сбросить игру можно кнопкой со стрелками в верхней части экрана.

Состав колоды и суммы ремонтов пока демонстрационные. Мультиплеер, сотрудники и расширение жилого фонда будут добавляться отдельными модулями.
